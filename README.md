# My First Website Refined

Full-stack web application featuring a poetry frontend and a FastAPI backend integrated with PostgreSQL (Neon.tech).

## Tech Stack
- **Backend:** FastAPI, SQLAlchemy, PostgreSQL (`psycopg`)
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Database:** PostgreSQL (Neon.tech)
- **DevOps:** Docker
